# Andrew Malkin

Hands-on CTO and systems architect in Portland, OR. I build production software by orchestrating fleets of AI coding agents, and I design the guardrails that keep agent-written code architecturally sound.

**Start here: [ratchets-before-code](https://github.com/ioitiki/ratchets-before-code).** It shows how I keep agent-written code from rotting:
- architectural invariants enforced as failing builds, landed before the code they protect
- every piece of work moves through a brief, a spec, a plan and a live-proof report

It's a small Rust job ledger built entirely that way by AI coding agents, with the full record of every decision, plan and CI run.

**What I work on**

- **Agent runtimes.** I'm the architect of gato-os, a deterministic kernel for long-running agents, and of Gato, a Rust agent platform with 40 releases in 7 months. Both are private.
- **Trading systems.** Co-founder and lead engineer of MFA Trading, a multi-strategy automated equities platform trading live capital.
- **On-chain finance.** I built an OP Stack L2 and a reserve-gated stablecoin for a digital-banking client.
- **Leading teams.** I'm CTO of Chainstarters (Techstars Boulder 2022), where my team built Official, the relationship app Bumble acquired in 2023.

Most of my work lives in private repositories. This profile is where the method is public.
